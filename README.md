# as.krivedko.kgam

Трансформирует любые ответы агента в классический Йазыг Падонкаф (Олбанский
йазыг) образца 2000-х годов. КГ/АМ. Аффтару пить йад.

Вдохновлено архитектурой [smixs/pohuy](https://github.com/smixs/pohuy) —
тот же способ доставки (скилл + output style + команда + хук), но другой
механизм: `pohuy` вставляет идиомы в обычную прозу, `krivedko` переписывает
орфографию прозы целиком, сохраняя код и технические детали байт в байт.

только окружающая их проза.

## Что внутри

- `skills/krivedko/SKILL.md` — ядро: активация, персистентность, уровни,
  правило неприкосновенности кода, Auto-Clarity
- `skills/krivedko/references/orfoart.md` — генеративные правила письма
  (аканье, иканье, «жи/ши»→«жы/шы», оглушение, «-тся»→«-ца» и т.д.) —
  покрывают любое слово, не только заученные мемы
- `skills/krivedko/references/slovar.md` — словарь культовых форм: превед
  медвед, аффтар жжот, зачот/низачот, выпей йаду, ниасилил многа букаф, ЗЫ,
  ИМХО, ППКС и другие
- `skills/krivedko/references/sceny.md` — регистр вердиктов (пять ступеней,
  не десять — падонкаффский беднее мата корнями, богаче готовыми фразами) и
  эталонные сцены
- `commands/krivedko.md` — `/krivedko [lite|full|ultra]`
- `output-styles/krivedko.md` — постоянный тон на всю сессию (устанавливается
  через `install.sh`, а не включён по умолчанию)
- `hooks/style-reminder.sh` — per-turn подкрепление стиля, чтобы тон не
  выцветал к сотому ходу
- `.claude-plugin/` — манифест плагина и маркетплейса для Claude Code
- `evals/evals.json` — тестовые промпты для `skill-creator`

## Уровни

| Level | Что меняется |
|-------|--------------|
| **lite** | Мангл на приветствиях и вердиктах, остальной текст обычный |
| **full** *(default)* | Орфография переписана по всей прозе, культовые фразы уместно вставлены |
| **ultra** | Максимальная плотность: без заглавных в начале фраз, восклицания, присказки на кульминации |

## Неприкосновенное

Код, команды, идентификаторы, строки ошибок, числа, URL — никогда не
переписываются. Коммиты, PR и документация — чистым языком: стиль живёт в
чате, в git-историю не течёт. На security-предупреждениях и необратимых
операциях (`DROP TABLE`, `rm -rf`, force push) стиль отключается до конца
критической части.

## Установка

```bash
# Claude Code — плагин (скилл срабатывает по /krivedko или явной фразе)
claude plugin marketplace add ast-ashulga/as.krivedko.kgam
claude plugin install krivedko@kgam
```

Включить как постоянный output style (одной командой, отдельное явное
действие — по умолчанию ничего не включается само):

```bash
curl -fsSL https://raw.githubusercontent.com/ast-ashulga/as.krivedko.kgam/main/install.sh | bash
```

**Включить на сессию:** `/krivedko` или скажи «пиши падонкаффским».
**Выключить:** «нормальный режим» / «хватит падонкаффского».
